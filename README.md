# Backend (Database + API Endpoint)

- Open VSCode and open New Terminal
- Type/paste "git clone https://github.com/OBM-Company-Profile/Backend" **(without "")** then enter
- To run the nodemon, input "npm run api-service" **(without "")** then enter
- To exit the process, pressing Ctrl + C then press "Y"

  

  **System Requirement**
  - Visual Studio Code
  - Node JS v20.16.0 (npm version : 10.8.1)
  - ExpressJS (Version 4.19.2)
  - XAMPP (for accessing phpMyAdmin)
  - Nodemon (Version 3.1.4)
  - Mysql (terminal installation)
